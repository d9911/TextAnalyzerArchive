# Text Analyzer Archive

[English](README.md) | [Español](README.es.md) | Русский

Text Analyzer Archive — лёгкая архивная браузерная версия счётчика текста с отдельной страницей для встраивания.

## Назначение

Предоставляет самодостаточный интерфейс подсчёта текста для самостоятельного использования или включения через прилагаемую страницу встраивания.

## Веб-адрес

[text-analyzer-archive.d9911.org](https://text-analyzer-archive.d9911.org/)

## Подтверждённые возможности

- Считает слова, символы с пробелами и символы без пробелов при изменении текста.
- Обновляется по событиям ввода, вставки и отпускания клавиши, настроенным в `src/i18n/config.json`.
- Предоставляет `index.html` для полного интерфейса и `embed.html` для компактной версии.
- Загружает конфигурацию и переводы из JSON, используя встроенные резервные данные в коде приложения.

## Использование

1. Откройте полное приложение или страницу встраивания.
2. При необходимости выберите язык интерфейса.
3. Введите или вставьте текст и прочитайте три счётчика.

## Локальный запуск

Конфигурация и переводы загружаются через `fetch`, поэтому репозиторий нужно раздавать по HTTP:

```bash
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000).

## Структура

- `index.html` — самостоятельный интерфейс; `embed.html` — компактная версия для встраивания.
- `src/script/` содержит загрузку конфигурации, локализацию, темы, подсчёт и инициализацию приложения.
- `src/i18n/` содержит базовые данные, конфигурацию и JSON-файлы языков.
- `src/style/` и `src/img/` содержат локальные стили, иконки и манифест.

## Интернационализация и темы

В конфигурации указаны английский, испанский, русский, французский и немецкий языки. Приложение сохраняет настройки языка и темы в локальном хранилище, определяет поддерживаемый язык браузера при отсутствии сохранённой настройки и предоставляет светлую и тёмную темы.

## Развёртывание

`wrangler.jsonc` объявляет приложение `text-analyzer-archive` и раздаёт статические ресурсы из корня репозитория (`.`).

## Технологии

Статические HTML, CSS и браузерный JavaScript; в корне репозитория нет манифеста пакетов.
